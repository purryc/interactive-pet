# Miso V1 验收记录

日期：2026-09-17。范围：iPad Safari 优先的逗猫棒、羽毛物理、猫自主响应、双指零食代理与本地记录。

## 已验证

- `npm test`：11 项通过；覆盖真实 v10 GLB 的 12 个动作与骨骼、羽毛停棒后继续移动且不穿地、原始／平滑输入分离、反应延迟、扑空后落地恢复、低位追逐、双指捏合抓取／松手掉落、CSV 数据结构。
- `npm run build`：成功生成静态站点。Three.js 主包产生体积提示，不影响构建。
- 桌面浏览器：V1 默认模式加载；点击场景后状态从「注意到了」变为「靠近」，逗猫棒和羽毛被绘制，控制面板与参数可展开，无页面错误。
- iPad Pro 12.9 模拟器 Safari：V1 页面加载，模型、状态、模式切换栏和高度控制在竖屏中可见，约 60 FPS；截图见 `ios_simulator_v1.png`。

## 真机与输入边界

- 已连接的设备为 iPad Pro 12.9 英寸第六代，iPadOS 26.5；它支持 Apple Pencil 悬停。但本轮尝试启动真机 Safari 时设备仍锁屏，系统拒绝启动，因此真实 Pencil 悬停、倾角、双指手势与帧率尚未实测。
- Safari 的标准 Pointer Events 可承载 XY、笔类型、倾角；没有标准离屏距离字段。页面仅在收到明确的距离值时标为设备距离，其他情况标为模拟高度，不能把倾角当作高度验收。
- 模型无独立眼球骨骼、前爪 IK 或吃食动作。V1 用头颈跟踪、预制伸爪动作和低头嗅闻；零食交互不声称完整吃食。

## 使用路径

在场景内移动 Pencil 或鼠标触发逗猫棒；调高「悬停高度」可测试扑跳。切到「双指零食」后，在零食附近双指捏合、移动并松开。展开「互动调试与记录」查看状态并按需导出 CSV。
