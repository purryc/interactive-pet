# Heihei Pencil 通道

这个轻量 iPad 应用承载与网页版相同的公开页面。网页悬停事件无法提供变化的笔角度时，应用通过 UIKit 的 `UIHoverGestureRecognizer` 读取方位、倾角和归一化悬停距离，传给页面内的 `heihei-pencil` 事件。双指触控继续由网页处理。

运行：用 Xcode 打开 `HeiheiHover.xcodeproj`，选择已连接的 iPad，并在自己的开发者团队下签名。应用使用公开网页，不包含模型副本或个人数据。底部状态条显示原生事件数与角度，便于在设备上验证。

`zOffset` 是设备归一化距离，不是厘米。需记录真机悬停和接触状态下角度是否随左右、前后倾斜变化；仅仅收到默认值不能算验收通过。
