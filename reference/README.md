# 参考与来源

- `character_sheet_original.png`、`action_sheet_original_01.png` 与 `quadruped_action_sheet_v10.png` 是项目委托人提供的角色和动作设定，v10 以最后一张四足设定为主要外观参考。
- 角色开发早期用 Hyper3D Rodin Gen-1.5 生成过模型。当前 v10 保留早期资产的贴图头脸与尾巴，身体和四肢在 Blender 中重新建模并绑定。仓库中的 v6 Blender 文件是重建输入。
- [Stripe the Cat](https://sketchfab.com/3d-models/stripe-the-cat-rigged-and-animated-2e3030b71a6d4b219fdc7304f8e58013)、[Cat Chubby](https://sketchfab.com/3d-models/cat-chubby-034eb323f0dc4510b7db82f9b4a5b8fb) 和 [Rusty Animator 猫步态教程](https://rustyanimator.com/cat-walk-cycle/) 用于观察四足姿态与步态；没有复制其网格、骨骼或动画数据。
- 猫后肢和前肢的骨链方向还参考了[明尼苏达大学兽医解剖资料](https://vanat.ahc.umn.edu/carnLabs/Lab07/Img7-8.html)。关节藏在卡通体表下，不按解剖图表现可见肌肉块。

这些来源记录用于说明创作过程；本仓库没有附授予第三方复用角色图像或模型的许可证。
